# Ocarina Knowledge

Knowledge base untuk analisis market research Ocarina. Pilih modul sesuai tipe studi dan output yang dibutuhkan.

## Study Context

### ./concept_product_study_context.html

Panduan untuk **Concept Test, Product Test, InnoTest, dan InnoCPT**, termasuk KPI, benchmark, study routing, dan aturan interpretasi.

### ./ua_study_context.html

Panduan untuk **Usage & Attitude Study**, termasuk profiling, awareness, usage, purchase behavior, brand funnel, association, ranking, dan open-ended analysis.

## Statistical Analysis

### ./sig_test_rendering_module.html

Aturan pemilihan significance test, confidence level, comparison letters, multiple-comparison correction, verification log, dan output rendering.

### ./rwa_chart_rendering_module.html

Panduan **Relative Weight Analysis**, model diagnostics, importance ranking, model fit, dan horizontal bar-chart rendering.

## Output Formatting

### ./table_format.html

Standar struktur tabel, label, row order, decimal precision, significance marker, serta format **Hedonic, Intensity, dan JAR**.

## Recommended Routing

| Request | Required Modules |
|---|---|
| Concept Test analysis | Concept & Product Study Context |
| Product Test analysis | Concept & Product Study Context |
| InnoTest or InnoCPT | Concept & Product Study Context |
| U&A analysis | U&A Study Context |
| Significance testing | Relevant Study Context + Significance Test Module |
| RWA or driver analysis | Relevant Study Context + RWA Module |
| Final table rendering | Relevant Study Context + Table Format |
| Complete analysis | Relevant Study Context + Analysis Module + Table Format |

## Usage Notes

1. Start with the relevant **study-context module**.
2. Add the **significance-test module** when testing differences between groups.
3. Add the **RWA module** for driver analysis or importance ranking.
4. Apply the **table-format module** to every final table.
5. Use project-specific definitions and supplied data before general methodology.
6. State assumptions, bases, exclusions, confidence levels, and limitations in every analysis.
